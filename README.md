
# 💧 Controle de Níveis de Água

Projeto desenvolvido em Python para simular o monitoramento de um reservatório de água, permitindo que o usuário escolha o nível desejado e visualize uma mensagem colorida no terminal.


## 🎨 Níveis do Reservatório

 Nível, Situação, Cor 
 1  Muito baixo (crítico)  🔴 Vermelho 
 2  Baixo  🟡 Amarelo 
 3  Médio  🟢 Verde 
 4  Alto   🩵 Ciano 
 5  Muito alto (alerta) 🔵 Azul

## 🛠️ Tecnologias

- Python
- Biblioteca Colorama

## 📦 Instalação

Instale a biblioteca pelo terminal:

pip install colorama


## ▶️ Como executar

escolha um número de 1 a 5 para a situação do reservatório.

## 📚 Objetivo

Praticar conceitos de programação em Python, como listas, funções, estruturas condicionais, repetição e utilização de bibliotecas externas.
